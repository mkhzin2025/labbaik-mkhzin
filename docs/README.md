# لبيك الذكي - منصة إدارة خدمة العملاء والنمو عبر القنوات الموحدة 🚀💎🤖

![Labbaik Banner](./labbaik-launch-poster.png)

**لبيك** هو مساعد ذكاء اصطناعي استراتيجي مصمم للمتاجر الطموحة لإدارة كافة محادثات العملاء (واتساب، إنستغرام، فيسبوك) ومراجعات جوجل ماب بذكاء عاطفي وتحليلي فائق، مما يحول البيانات إلى أرباح ووقت موفر.

---

## 🔥 المميزات الرئيسية (النسخة الحالية - المرحلة الرابعة)

### 1. لوحة استخبارات الأعمال (Interactive Dashboard) 📊📈
رؤية 360 درجة لمتجرك عبر رسوم بيانية حية تظهر:
- حجم التفاعل اليومي ومؤشر السعادة.
- حساب "الوقت الموفر" (Hours Saved) بفضل لبيك.
- مقارنة سرعة الرد بين الذكاء الاصطناعي والرد البشري.

### 2. التنظيم الذكي بالوسوم (Smart Tagging) 🏷️🔍
فرز آلي ويدوي للمحادثات (طلب جديد، شكوى، VIP) مع نظام فلترة متقدم يسمح بعزل القنوات والوسوم للتركيز على المهم أولاً.

### 3. ترسانة العقول الجبارة (Multi-AI Models) 🚀🧠
التحكم الكامل في "عقل لبيك" مع إمكانية التبديل بين أذكى المحركات العالمية:
- **DeepSeek-R1:** للدقة والذكاء الفائق.
- **Groq (Llama 3.1):** للسرعة الصاروخية.
- **Gemini & OpenAI:** كأنظمة احتياطية موثوقة.

### 4. إدارة السمعة والخرائط 📍⭐
مراقبة تقييمات جوجل ماب والرد عليها آلياً بلهجة سعودية فخمة ومنضبطة لتعزيز حضورك الرقمي.

### 5. صندوق الوارد الموحد (Omnichannel Inbox) 📥
إدارة (WhatsApp, Instagram, Facebook) في واجهة واحدة موحدة بلمسات "سايبر" عصرية.

### 6. السيطرة التشغيلية ⏳⚙️
تحديد ساعات العمل، وضعية الصمت التلقائي عند تدخل البشر، وتنبيهات فورية (سطح مكتب وأصوات) للعملاء الغاضبين.

---

## 🛠️ البنية التقنية (Tech Stack)

### الباك إند (Backend)
- **NestJS:** للهيكلية المتطورة.
- **PostgreSQL & MongoDB:** لتخزين البيانات العلائقية والمحادثات.
- **Socket.io:** للتواصل اللحظي.
- **Recharts Logic:** لمعالجة البيانات التحليلية.

### الفرونت إند (Frontend)
- **React.js & TypeScript:** للأداء المستقر.
- **Tailwind CSS v4:** للواجهات الفخمة.
- **Recharts:** للرسوم البيانية التفاعلية.
- **Lucide Icons:** للأناقة البصرية.
